# Eagle用プラグイン：Selected Images to Documents

このプラグインは画像管理ソフト「Eagle」向けに開発された、AI生成画像とそのプロンプトを効率的にドキュメント化するためのツールです。

## 主な機能と使用フロー

1. AI生成画像をEagleにインポート
2. 生成時のプロンプトテキストをクリップボードにコピー
3. Eagle内で対応する画像を選択し、プラグインを起動
4. プラグインがAPI経由でHTML形式のテーブル化された画像とプロンプトテキストを生成
5. 生成されたコンテンツをObsidianなどのマークダウンエディタに貼り付け
6. 画像プレビューとプロンプトを含む参照可能なドキュメントが完成

## 技術的特徴
- ローカルサーバーを使用してEagle内の画像ファイルを外部から参照可能に
- HTML/マークダウン形式での出力により、Obsidianなどのエディタでの画像プレビュー表示に対応
- ワンクリックで必要な情報（画像テーブル、プロンプト）をまとめて生成

## メリット
- AI画像生成の試行錯誤プロセスを効率的に記録
- 成功したプロンプトとその結果を視覚的に管理
- 後から参照しやすいドキュメント形式での保存が可能
